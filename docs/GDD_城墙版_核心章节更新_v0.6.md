### 2.2 五大差异化卖点（替换原列表）

1. **题材差异化**：中式诡异奇幻。符箓、傩面、纸扎、风水、五鬼运财、百鬼夜行——在塔防小游戏赛道几乎空白，且《纸嫁衣》《黑神话》已验证中式诡异有受众基础与情绪溢价。

2. **城墙守备+五灵异质火力**：五名御灵立于城墙之上，各自以完全不同的攻击形态作战——锥形AOE冲击波、弹射追踪剑气、扇形弹幕灼烧、青灯标记集火、蓄力金针落雨。五种火力编织成守城网络，在靶心like赛道创造了无可对标的视觉密度��协同深度。

3. **双层肉鸽**：局内符箓构筑+局外道行永久变异树（Hades式Meta肉鸽）。参考产品都是单层局内随机，本作让"失败的局"也产出永久成长，降低挫败、提升复局动机。

4. **阴阳双资源+百鬼夜行**：阳气驱动御灵必杀、阴气击杀积累；阴气满槽可主动触发"百鬼夜行"——屏幕染红、音效变调、鬼潮加剧，但玩家获得短暂强化。靶心like唯一的"恐怖紧张感"节奏控制器。

5. **凶兆镇煞/迎煞**：每关有"凶兆"词缀（血月/纸人分裂/鬼雾），玩家可消耗资源"镇煞"消除，或"迎煞"保留换取奖励翻倍。关卡级主动风险博弈��参考产品无此设计。

### 4.1 御灵守备系统（城墙战斗核心）——替换原 4.1"御灵召唤系统"

**目的**：提供可收集、可养成、可配阵的战斗单元，承载 P4"鬼有所归"。五个御灵立于城墙五个固定哨位，各自以完全不同的攻击形态组成火力网。

**玩家幻想**：御灵师镇守孤城，五灵立于城头——每一位的出手方式都是独特的道法显化，五种火力在城墙前��编织成一道死亡之网。

**城墙站位模型**（已实现）：
- 五灵固定哨位呈弧线排列，中间突出、两侧收拢，形成天然远近纵深：
- 左翼(青衣 y=1045) ← 左前(红衣 y=999) ← 正中(黄巾 y=1003) → 右前(素问 y=999) → 右翼(玄鸦 y=1048)
- 正中位（黄巾）最先接敌、火力密度最高；翼位（青衣/玄鸦）更安全但输出窗口稍窄。站位本身构成火力分配策略。

**五灵攻击形态**（已实现，品类最丰富的异质火力）：

| 御灵 | 定位 | 攻击形态 | 机制特色 |
|------|------|---------|---------|
| 黄巾 | 前排锥形AOE | 锥形冲击波，前方扇形范围 | 对密集鬼潮清场，靠墙最近火力最猛 |
| 红衣 | 中排DOT爆发 | 扇形弹幕+灼烧叠加+莲华引爆 | 多段机制叠加，输出天花板 |
| 玄鸦 | 后排追踪狙击 | 弹射追踪剑气，可穿透追击多目标 | 机动火力，漏怪补刀 |
| 素问 | 中排蓄力奶 | 蓄力金针落雨+全队治疗 | 输出治疗混合，续航保障 |
| 青衣 | 后排标记辅助 | 青灯标记"照破"+全队集火增伤 | 辅助不只是奶，"标记-集火"协同 |

- 阴阳：阳灵（直接伤害型）/阴灵（控制辅助型）

### 4.3 城墙守备系统（新增，替代原 4.3"风水阵法"）

> 原"风水阵法（5x3盘/阵位五行/阵法共鸣）"因角色不下场而失效。
> 替代为城墙守备系统，承载 P3"万法归阵"。

**目的**：提供塔防的空间维度与可见的失败压力，承载 P3。

**玩家幻想**：御灵师守在城头，看鬼潮一波波撞击城墙——墙体在撞击中碎裂、火星飞溅、墙段告急——这不是抽象的"基地血量-1"，是肉眼可见的城墙在崩塌。

**城墙模型**（已实现基础版，需扩展）：

**基础参数**：
- 城防HP：[PLACEHOLDER] 初始1000（已实现）
- 城墙防线Y坐标：930（已实现，敌人脚点到达此线开始攻击城墙）
- 城墙视觉：横向防守线+墙体纹理+受击碎裂粒子

**墙段系统**（v0.7+扩展）：
- 城墙分为3段：左段/中段/右段
- 每段对应覆盖的哨位：
  - 左段：青衣+红衣的防守区域
  - 中段：黄巾的防守区域（最突出，承受压力最大）
  - 右段：素问+玄鸦的防守区域
- 单段被攻破 → 该段对应御灵攻击力/攻速减半，直至修复
- 全线崩溃 → 败北

**城墙状态机**：
```
完整(HP>60%) → 受损(HP 30-60%，出现裂缝视觉) 
             → 告急(HP<30%，墙体碎裂+警报)
             → 崩裂(单段HP=0 → 该段御灵减益)
             → 全线崩溃 (败北)
```

**城墙技能**（局内肉鸽的一层新选择）：
- 作为符箓卡池中的"城防符"类别出现
- 效果示例：
  - 滚木：[PLACEHOLDER] 城墙前方释放滚木，击退并伤害触及城墙的敌人
  - 火油：[PLACEHOLDER] 城墙防线前方燃烧区域，持续灼烧经过的敌人
  - 符咒结界：[PLACEHOLDER] 城墙获得临时护盾，吸收伤害
  - 城墙修复：[PLACEHOLDER] 恢复一段城墙HP

**成功条件**：玩家在城墙告急时有真实紧迫感，会说"中段快破了，我得赶紧把黄巾的输出拉满"
**失败状态**：城墙只是一个血条无分段，破了就输了无中间状态
**边界**：城墙技能占符箓卡池比例[PLACEHOLDER] 15%；每局城墙修复次数有限
**调优杠杆**：城防HP、墙段数量、单段崩裂后的减益幅度、城墙技能强度
**依赖**：御灵守备系统（4.1）、符箓系统（4.2）

### 4.5 诡事凶兆（关卡级风险博弈）

> **核心原则（v0.6新增）**：推进度的内容不做凶兆，刷资源的内容做凶兆，挑战的内容凶兆是主题。

**凶兆投放分层**：

| 场景 | 凶兆 | 理由 |
|------|------|------|
| 主线首通 | **不做** | 所有人同一赛道，不能因难度选择分成阶级；首通奖励固定且唯一 |
| 诡事复刷 | 可选 | 通关后的日常资源本，迎煞=刷材料效率+20-30%（有每日上限/可追赶） |
| 镇魂塔/阴阳阵 | 核心 | 自选词缀叠加=挑战乐趣，奖励为排行/称号/幻形（社交性/不影响养成天花板） |
| 赛季关卡 | 固定 | 所有人同一套词缀，同一起跑线 |

**设计意图**：凶兆拉开的差距在"资源获取频率"而非"内容进度天花板"。养成材料有每日上限→追得上。首通奖励固定唯一→不存在"别人拿了2x我永远拿不到"。

**凶兆词缀设计三��度**（原内容展开）：

1. **影响战斗节奏**：血月（鬼物暴击+30%）、鬼雾（视野缩小/射程-20%）、疾走（鬼物移速+25%）
2. **改变敌人行为**：纸人（死亡分裂）、回煞（每3波复活）、铁甲（减伤20%）
3. **改变资源博弈**：阴蚀（阴气积累-30%）、阳衰（阳气回复-20%）
4. **城墙相关（v0.6新增）**：裂墙（初始HP-20%）、脆壁（受击伤害+30%）、薄弱中段（中段HP单独-40%）

**镇煞vs迎煞经济模型**：
- 镇煞：消耗铜钱/灵玉→移除凶兆→奖励100%
- 迎煞：不花钱→保留凶兆→奖励200%+稀有碎片概率
- 零氪更倾向迎煞（省钱），付费玩家有选择权（不缺铜钱但缺碎片也会迎煞）

| 守城器械 | 解锁城墙技能槽位（滚木/火油/符咒结界等） | 随城防等级解锁 |
| 城防科技树 | 被动加成（城墙减伤%/修复速度%/墙段崩裂后恢复速度） | 消耗道行点（复用Meta树资源） |

**边界**：城防养成不与御灵养成共享核心资源（铜钱除外），避免玩家在"养人还是养墙"中纠结。
**设计意图**：城墙养成=低门槛的"安全感投资"（零氪玩家也能感受到城池变强），法器洗练=高门槛的"极限追求"（大R付费深度）。两者不冲突。
