# 局内强化池配置规范 v0.1

整理日期：2026-07-28
适用版本：御灵召来_城墙版 Wall Mode
定位：局内强化池的设计纪律、叠加规则、抽取规则的唯一权威来源。各角色文档与本规范冲突时，以本规范为准。

---

## 1. 设计纪律：机制唯一归属原则（最高优先级）

**起因**：红衣、玄鸦、素问的升星表与局内强化链出现多处效果重复（素问 5 星锁定 vs 观星锁命 3 星、玄鸦 3 星阈值 vs 群鸦窥命 2 星阈值、红衣 4 星业火值需求 vs 业火速燃）。事后用"取最高值"和"剔除/替换"收口是被动的——正确做法是在设计之初就分开。

### 1.1 核心规则

| 效果类型 | 归属规则 | 理由 |
|---|---|---|
| **机制**（二元效果：有/无，如锁定、穿透、斩杀线、标记规则） | **唯一归属**：局内 或 局外，只能有一个主人 | 重复 = 死卡 |
| **数值**（连续参数：攻击 +10%、伤害 +20%） | 允许多源 | 重复只是稀释，用"取最高 / 最终替换 / 加算"收口，不产生死卡 |

### 1.2 两个系统的货架分工

- **局外（升星）卖**：新能力（局内池里没有的机制）、手感/QoL（弹道速度、预兆时间、索敌保留）、身份机制（核心玩法的永久版）
- **局内（强化）卖**：当局构筑分支（流派选择）、数值放大（当局）、机制变体（每 N 次触发、条件触发）

一句话：**升星买"局内拿不到的东西"，强化强化"这局选择的东西"**。

### 1.3 执行方式：归属登记表

每个角色设计定稿前，必须填一张机制参数归属表，冲突在文档阶段解决，不允许拖到卡池阶段：

| 机制参数 | 归属（局内/局外） | 备注 |
|---|---|---|
| 例：斩杀线阈值 | 局内（群鸦窥命 2 星） | 升星不再提供 |
| 例：锁定规则 | 局外（素问 5 星） | 局内 3 星改做容错效果 |

### 1.4 现有内容审计结果（待策划确认归处）

| 冲突 | 现状 | 建议归处 |
|---|---|---|
| 玄鸦斩杀线阈值：升星 3 星 35→40% vs 群鸦窥命 2 星 35→45% | 旧设计双源，靠"取最高"收口 | **归局内**（斩杀深度是当局构筑选择）；玄鸦升星改卖鸦痕持续、索魂、暗影溅射、命尽归鸦等局内拿不到的新能力 |
| 素问锁定规则：5 星观星不移 vs 观星锁命 3 星 | 旧设计存在同效风险 | 已拆分：局外 5 星卖"星蚀跨目标保留"，局内 S04 卖"问命计数短保留 / 本局节奏容错"，不再设计永久锁定死卡 |
| 红衣业火值速率：4 星需求降低 vs 业火速燃 | 旧设计双源 | **归局内**（蓄力节奏是当局构筑）；红衣升星不再减少业火需求，改卖开局业火、索敌手感、赤莲本相等永久身份 |

## 2. 数值叠加规则（多源数值的收口方式）

汇总自玄鸦/素问正式数据，全局适用：

1. **同类阈值不叠加，取最高值**。例：鸦痕触发血线 基础 35% / 局内 45% → 最终 45%；正式升星不再提供同类血线阈值
2. **同类伤害倍率按最终替换，不重复加**。例：鸦痕目标增伤 基础 20% / 局内 35% → 最终 35%；正式升星不再提供同类鸦痕增伤
3. **层数/层伤取最高值**。例：星蚀每层增伤 基础 6% / 星针入骨 2 星 8% → 最终 8%，不会变成每层 14%
4. **额外攻击类机制（穿透/弹射/追加/溢出转移）可共存**，但每个机制有独立触发限制
5. **概率类效果取最高值，不做多次独立判定**。例：小星针概率局内 25% / 40% → 40%；正式升星不再提供同类小星针概率
6. **锁定/标记类规则不重复叠加**，只生效一次
7. **加算区写死口径**：同名加算区内数值相加（如天命归一：180% + 层数×8% + 满层 30%），不与基础倍率独立乘算
8. **奖励伤害不染指机制**：小星针、追命鸦刃、旁落星蚀、灼魂回响、暗影溅射等奖励伤害，不叠层、不触发自身、不计入节奏计数、不产出业火符、不挂新鸦痕
9. **持续时长类效果默认加算**。例：赤莲火区基础 1.5s + 局内 0.5s + 升星 0.3s = 2.3s

### 连锁禁止清单（死规则）
- 追命鸦刃造成的击杀，不再触发新的追命鸦刃
- 溢出转移每次击杀至多 1 次；转移造成的击杀不再触发转移、不触发追命鸦刃
- 转移/奖励伤害只吃本次实际溢出，上限 80% ATK
- 玄鸦索魂由任意友方（含玄鸦自身）击杀鸦痕目标触发；同一帧 / 同一次范围伤害击杀多个鸦痕目标时，至多获得 1 层；索魂最多 3 层
- 红衣灼烧凝符可以跨敌人累计，但默认每秒至多凝聚 1 枚业火符，作为可配置保险丝

### 全局紧急索敌规则

定位：这是 Wall Mode 的基础战斗安全规则，解决“怪物已经快打城墙了，御灵还在打远处目标”的割裂感。

- 敌人进入城防预警线时，非硬锁御灵下一次普攻优先攻击该敌人。
- 城防预警线暂定：距离城防攻击线 ≤180px，或预计 1.6s 内进入攻击城防状态。
- 多个紧急目标同时存在时，优先级：已开始攻击城防 > 距离城防最近 > 当前生命百分比最低。
- 已发出的弹道、已锁定落点的落针、大招锁定目标，不因紧急索敌临时拐弯。
- 素问 S04 的软锁定会被紧急索敌覆盖。
- 黄巾 4 星「守门本能」是紧急索敌的强化版，而不是另一套独立规则。

## 3. 死卡禁止与剔除/降级规则（保险丝）

> 定位：这是**保险丝**，不是设计方法。设计阶段按第 1 节纪律执行，本节只兜漏网之鱼。

1. **禁止出现"选择后只是不重复叠加"的死卡**
2. 局外已提供某完整机制 → 局内同效果节点**不得作为可选结果出现**
3. 强化链前两星仍有效、仅第三星与局外重复 → 第三星**替换为不同效果**（参照素问：旧锁定拆成局外星蚀跨目标保留 + 局内问命计数容错）
4. 整条链被局外覆盖 → 该链从本局强化池**剔除**
5. 替换优先级：**机制补强 > 数值补强 > 不出现**

## 4. 抽取规则

### 4.1 两级抽取
```
升级触发三选一时：
第一步：先抽角色倾向（基础各 20%；权重向本局专属强化点数较少的角色倾斜，防滚雪球）
第二步：从该角色"当前可解锁的链/节点"中抽一条呈现；最终呈现对象永远是可用强化节点，不是裸角色
```

### 4.2 限制
- 同一角色连续出现 ≤2 次
- 大招牌解锁口径（全角色统一）：**该角色累计获得 4 次“专属强化”后，其大招牌进入该角色强化池**（按角色计数，不按全局；通用强化、阵营强化、其他角色专属强化不计入；觉醒牌占一次三选一选择位）
- 精英怪爆发奖励：随机 2~5 个可用节点
- 每局 1 次免费刷新三选一

### 4.3 全局兜底
- 全局词条（城防回血 / 全队攻击 / 计策回能等）约占池子 15%，三选一永远有"安全牌"
- 城防回复类必须至少 2 条（避免青衣成为必修位）
