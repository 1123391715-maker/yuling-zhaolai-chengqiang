# 《御灵召来》局内角色技能、强化与基础关卡设计 v0.1

> 目标：基于当前已有 5 个角色素材、3 个敌人素材，先形成一版可以落地到战斗 demo 的局内内容设计。  
> 当前设计优先服务“5 角色下场自动战斗 + 割草感 + 局内肉鸽强化 + 局外抽卡养成”。

---

## 1. 设计原则

### 1.1 阵营与职业

阵营暂定：

- 普通阵营：人族、修士、妖族、鬼族
- 稀有阵营：神、魔

职业暂定：

- 坦克：承伤、阻挡、护盾、减伤
- 战士：近战输出、收割、贴身清怪
- 输出：远程/法术/爆发/DOT，主要负责清怪
- 辅助：治疗、护盾、增益、控制

当前 5 个角色覆盖方式：

| 角色 | 阵营 | 职业 | 战斗定位 |
|---|---|---|---|
| 黄巾 | 人族 | 坦克 | 前排阻挡、同列保护、阵线核心 |
| 红衣 | 鬼族 | 输出 | 灼烧、全场火雨、持续伤害核心 |
| 青衣 | 修士 | 辅助 | 群体治疗、护盾、治疗光环 |
| 玄鸦 | 妖族 | 战士 | 近战连斩、突进收割、处理精英 |
| 素问 | 神 | 输出 | 远程星针、破防标记、神罚爆发 |

> 说明：当前没有“魔”阵营角色，魔阵营强化可以先作为预留，不进入当前 demo 刷新池。

### 1.2 强化类型

局内强化先控制为 3 类，避免系统过重：

| 类型 | 作用 | 强度定位 |
|---|---|---|
| 通用强化 | 全队都能吃到，保证不废牌 | 稳定，单张强度最低 |
| 阵营强化 | 强化某个阵营，引导流派 | 中高强度，需要阵容条件 |
| 角色专属 | 强化单个角色的核心玩法 | 单体最强，制造爽点 |

稀有度：

| 稀有度 | 设计方向 |
|---|---|
| 普通 | 基础数值，可升级居多 |
| 稀有 | 数值 + 条件机制，部分可升级 |
| 传说 | 机制质变，通常不可升级 |

可升级强化建议最多 3 级：

- Lv.1：给方向
- Lv.2：给强度
- Lv.3：给机制质变

## 2. 五个角色技能设计

### 2.1 黄巾

定位：人族 / 坦克 / 前排守阵

基础属性：

| 属性 | 数值 |
|---|---:|
| HP | 1000 |
| ATK | 40 |
| DEF | 60 |
| 攻速 | 0.8/s |
| 阻挡数 | 3 |
| 射程 | 1 格 |

普攻 — 盾击

- 挥动巨盾砸向面前敌人。
- 伤害：100% ATK，约 40 点
- 范围：同列前排 1 格
- 节奏：前摇 0.25s / 命中 / 后摇 0.35s
- 每 1.25s 一次
- 命中时：目标 30% 概率被击退半格

大招 — 坚壁领域

- CD：14s
- 黄巾举盾展开金色盾阵。
- 自身获得最大 HP × 30% 的护盾，持续 6s
- 护盾存在期间，同列所有友方英雄受到伤害 -25%
- 释放瞬间获得 0.15s 无敌帧

被动 — 不动如山

- 站得越久越硬。
- 战斗中每存活 10s，DEF 永久 +8%
- 最多 5 层，即 +40%
- 魂归复活后层数保留

表现重点：

- 黄巾应该是“阵线锚点”，怪物靠近后明显被他拦住。
- 盾击命中要有重感：屏幕小震、盾面闪光、敌人短暂停顿。

### 2.2 红衣

定位：鬼族 / 输出 / 灼烧群攻

基础属性：

| 属性 | 数值 |
|---|---:|
| HP | 450 |
| ATK | 100 |
| DEF | 15 |
| 攻速 | 0.9/s |
| 阻挡数 | 1 |
| 射程 | 3 格 |

普攻 — 火球术

- 掷出火焰弹。
- 伤害：100% ATK，约 100 点
- 范围：同列 1-3 格，远程
- 弹道速度：350px/s
- 节奏：前摇 0.3s / 命中 / 后摇 0.35s
- 每 1.11s 一次
- 命中后灼烧目标：每秒 15% ATK 伤害，持续 3s，不可叠加

大招 — 焚天火雨

- CD：18s
- 召唤火雨覆盖全场。
- 对所有敌人造成 45% ATK 伤害，约 45 点
- 命中后灼烧所有目标：每秒 12% ATK 伤害，持续 4s
- 调整目的：火雨用于铺火压血，不直接清屏；普通怪会在后续灼烧/普攻中陆续倒下
- 释放时自身获得 0.3s 无敌

被动 — 余烬

- 灼烧就是伤害放大器。
- 场上每有 1 个被灼烧敌人，自身 ATK +8%
- 最多 +40%

表现重点：

- 红衣是清屏爽点角色。
- 火球速度不能太快，要让玩家看到“丢出去、飞过去、炸开”。
- 大招释放时建议有红色屏幕边缘火光和技能名弹出。

### 2.3 青衣

定位：修士 / 辅助 / 治疗护盾

基础属性：

| 属性 | 数值 |
|---|---:|
| HP | 600 |
| ATK | 35 |
| DEF | 35 |
| 攻速 | 0.9/s |
| 阻挡数 | 1 |
| 射程 | 2 格 |

普攻 — 圣光弹

- 发射光弹，伤害较弱。
- 伤害：80% ATK，约 28 点
- 范围：同列 1-2 格，中程
- 弹道速度：380px/s
- 每 1.11s 一次

大招 — 群体治愈

- CD：13s
- 吟唱圣光，治愈全队。
- 全队回复 200% ATK 的 HP，约 70 点
- 全队额外获得治疗量 50% 的护盾，持续 4s

被动 — 圣光眷顾

- 自动治疗最低血量队友。
- 每 3s 自动为血量百分比最低的友方英雄回复 100% ATK，约 35 点
- 优先治疗非满血单位，满血单位不触发

光环 — 圣光庇护

- 出场即生效。
- 周围 2 格内所有友方英雄受到的治疗效果 +30%
- 青衣自身不受该光环加成

表现重点：

- 青衣的价值不是杀怪，而是“队伍突然稳住”。
- 大招应该有全队头顶柔光、护盾外圈、绿色/青蓝回血数字。

### 2.4 玄鸦

定位：妖族 / 战士 / 近战收割

基础属性：

| 属性 | 数值 |
|---|---:|
| HP | 720 |
| ATK | 78 |
| DEF | 28 |
| 攻速 | 1.15/s |
| 阻挡数 | 2 |
| 射程 | 1 格 |

普攻 — 鸦影斩

- 贴身挥刃斩击。
- 伤害：100% ATK，约 78 点
- 范围：同列前排 1 格，近战
- 节奏：前摇 0.18s / 命中 / 后摇 0.28s
- 每 0.87s 一次
- 命中后施加“裂伤”：每秒 12% ATK 伤害，持续 2s，不可叠加

大招 — 玄鸦掠阵

- CD：15s
- 玄鸦化作黑羽掠过敌阵后回到原位。
- 选择当前血量最高的非 Boss 敌人；若 Boss 在场，优先 Boss
- 对目标及其附近小范围敌人连续斩击 3 次
- 每段造成 90% ATK 伤害，总计 270% ATK
- 被命中的敌人获得“破绽”，持续 4s
- 破绽：受到来自战士/坦克的伤害 +20%

被动 — 鸦羽追击

- 攻击破绽目标或击杀敌人后，玄鸦攻速 +20%，持续 3s
- 最多叠 3 层
- 叠满时下一次普攻变为小范围横扫，造成 130% ATK 伤害

表现重点：

- 玄鸦要像“切进怪堆又退回来”的战士，不要真的长期脱离站位。
- 大招可用残影、黑羽拖尾、三段斩光表现。

- 范围：同列 1-3 格，远程
- 弹道速度：430px/s

大招 — 太素星落

- CD：17s
- 在敌人最密集区域落下星阵。
- 范围：半径约 170px
- 造成 5 次星落打击，每次 50% ATK，总计 250% ATK

- 破法：DEF -20%，受到技能伤害 +12%

表现重点：

- 素问是“高级输出/破防核心”，她不一定清小怪最快，但能让精英和 Boss 更快倒。
- 大招建议用蓝白星阵、落点闪烁、敌人身上出现命签符号。

### 3.4 刷新规则建议

每次升级三选一：

- 必出 1 张通用强化，避免全是窄牌
- 剩余 2 张从阵营/专属池随机
- 阵营牌只根据当前上阵阵营进入池子
- 专属牌只根据当前上阵角色进入池子
- 魔阵营当前没有角色，不进入当前 demo 刷新池
- 已满级强化不再出现
- 玩家选过某个可升级强化后，该强化后续出现权重略微提高

推荐权重：

| 条件 | 通用 | 阵营 | 专属 |
|---|---:|---:|---:|
| 默认 | 45% | 40% | 15% |
| 已选过某阵营强化 | 40% | 45% | 15% |
| 某角色星级较高 | 40% | 35% | 25% |

## 4. 敌人设计

当前只设计 1 个普通怪、1 个精英怪、1 个 Boss，全部可复用现有 3 个敌人素材。

### 4.1 普通怪：符纸游魂

素材：`enemy-wisp.webp`

定位：数量多、血低、制造割草感

| 属性 | 数值 |
|---|---:|
| HP | 78 |
| ATK | 28 |
| DEF | 0 |
| 移速 | 55 |
| 攻速 | 1.0/s |
| 攻击范围 | 近战 |
| 破阵伤害 | 18 |

技能：无

表现：

- 小体型、成群出现
- 死亡时爆出小纸屑/魂火
- 主要负责提供击杀反馈和局内升级进度

- 若目标被青衣护盾保护，则伤害 -35%

技能三 — 破阵跪拜

- Boss HP 降到 70% / 40% / 15% 时各触发一次
- 短暂吟唱 1.5s
- 对阵法造成 180 点伤害，并使所有敌人移速 +20%，持续 5s

表现：

- Boss 出场需要屏幕暗角和“纸扎魇主”大字提示
- 破阵跪拜要有明显蓄力，让玩家感到“这一段要撑住”
- 30% 血以下进入狂暴，红线和纸屑效果增强
