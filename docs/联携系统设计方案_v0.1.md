# 御灵召来 · 联携系统设计方案 v0.1

> 回应领导"策略深度不够"的反馈。核心思路：将卡牌品类的阵容博弈深度注入塔防节奏。
> 设计原则：MVP可落地（不超单人产能）、决策感强（联携触发=玩家感觉到自己做了正确判断）、视觉清晰（选牌时能看懂）。

---

## 一、三重联携框架

```
┌─────────────────────────────────┐
│        三重联携框架               │
│                                 │
│  1. 阵位联携 → 相邻触发          │ ← 基础层，最容易理解
│  2. 技能联携 → 选牌触发          │ ← 核心层，策略深度的来源
│  3. 阵容联携 → 上场前触发        │ ← 终极层，局外配阵的回报
└─────────────────────────────────┘
```

三层结构对应三种玩家决策时刻：
- **阵位联携**：战斗中，"我把红衣放在黄巾旁边" ← 即时空间决策
- **技能联携**：强化选牌时，"选这张牌能让红衣和青衣联动" ← 局内构筑决策
- **阵容联携**：开局前，"我选这五个御灵上场" ← 局外配阵决策

## 二、阵位联携（第一层·战斗内即时）

### 2.1 规则

- **触发条件**：两个御灵的守备范围产生重叠区域
- **生效条件**：联携御灵同时存活且都在守备锚点上
- **联携效果**：为该重叠区域施加增益/减益

### 2.2 联携组合表（首发5御灵）

| 联携名 | 触发组合 | 条件 | 效果 |
|---|---|---|---|
| **焚葬阵** | 红衣 + 黄巾 | 红衣守备范围覆盖黄巾所在锚点 | 黄巾每阻挡一个敌人，红衣对该区域伤害+8% [PLACEHOLDER] |
| **霜焰阵** | 红衣 + 青衣 | 同上述 | 红衣灼烧的敌人被青衣攻击时，减速效果翻倍 [PLACEHOLDER] |
| **守魂阵** | 黄巾 + 青衣 | 同上述 | 黄巾防御+15%；青衣每减速一个敌人，黄巾获得相当于其生命值3%的护盾 [PLACEHOLDER] |
| **狙击阵** | A（精英猎手）+ 任一 | A守备范围覆盖友方锚点 | A对正被友方阻挡的敌人伤害+25% [PLACEHOLDER] |
| **护佑阵** | B（治疗）+ 任一 | B守备范围覆盖友方锚点 | 友方受击时，B自动对其释放单体治疗(CD 6s) [PLACEHOLDER] |

### 2.3 玩家感知设计

- **选牌提示**：阵位联携不依赖选牌，只要距离够就生效。但选牌时的提示里会标注"当前阵位下已激活的联携"
- **视觉反馈**：两个联携御灵之间出现**水墨连线**（半透明），重叠区域地面出现**微光印记**
- **动画反馈**：联携触发时（如黄巾阻挡敌人→红衣伤害提升），红衣身上短暂燃起黄色光晕

## 三、技能联携（第二层·局内构筑核心）

### 3.1 规则

- **触发条件**：两个御灵分别选到**指定技能线节点**
- **生效时机**：选择该强化牌时立刻激活，**全期有效**
- **选牌提示**：强化牌卡面上显示"🔗 与 [御灵名] 的 [技能名] 形成联携"

### 3.2 技能联携表

#### 3.2.1 红衣的联携

| 联携名 | 红衣技能 | 搭档御灵 | 搭档技能 | 联携效果 |
|---|---|---|---|---|
| **炎壁** | 灼烧（普攻线节点3） | 黄巾 | 坚壁（被动线：防御+30%） | 黄巾阻挡的敌人全部附带灼烧（红衣不用一个个打） |
| **炎狱** | 叠灼（普攻线节点5） | 青衣 | 冰封（被动线：减速→冻结概率） | 灼烧层数≥2的敌人被青衣攻击时有20%概率冻结 [PLACEHOLDER] |
| **炎猎** | 爆燃（普攻线节点7） | A | 弱点标记（被动线：优先攻击最低血量敌人） | A攻击灼烧目标时，伤害增加至爆燃伤害的50% [PLACEHOLDER] |
| **炎愈** | 灼烧（普攻线节点3） | B | 治疗波（被动线：群体治疗） | B治疗友方时，同时对灼烧目标造成等量伤害 [PLACEHOLDER] |

#### 3.2.2 黄巾的联携

| 联携名 | 黄巾技能 | 搭档御灵 | 搭档技能 | 联携效果 |
|---|---|---|---|---|
| **坚盾** | 坚壁（被动线：防御+30%） | 青衣 | 凝滞（被动线：减速区域扩大） | 黄巾防御翻倍；青衣减速区域内的敌人对黄巾伤害减半 |
| **反噬** | 荆棘（被动线：受击反弹） | A | 穿透射击（普攻线：攻击穿透首个目标） | A的穿透射击每穿过一个敌人，黄巾反弹伤害+15% |
| **战吼** | 坚壁（被动线：防御+30%） | B | 治疗波（被动线：群体治疗） | B治疗黄巾时，黄巾获得"下一次受击反弹伤害×2" |

#### 3.2.3 青衣的联携

| 联携名 | 青衣技能 | 搭档御灵 | 搭档技能 | 联携效果 |
|---|---|---|---|---|
| **碎冰** | 冻结（被动线：减速概率→冻结） | A | 弱点标记（被动线） | A攻击冻结目标必暴击 [PLACEHOLDER] |
| **冰盾** | 凝滞（被动线：减速区域扩大） | B | 护盾（被动线：单体护盾） | B对青衣的护盾持续期间，青衣减速区域范围扩大50% |

### 3.3 玩家感知设计（技能联携是核心）

#### 3.3.1 强化牌卡面布局

```
┌──────────────────────────────┐
│ 🔴 红衣 · 灼烧               │ ← 御灵图标+技能名
│ 普攻线 节点3                │
│                              │
│ 火球命中附加灼烧             │ ← 效果简述
│ 3s内每秒30%攻击力火伤        │
│                              │
│ 🔗 炎壁：与黄巾·坚壁联携     │ ← 联携提示（高亮）
│    黄巾阻挡的敌人全附带灼烧   │
│                              │
│ [ 选择 ]                     │
└──────────────────────────────┘
```

联携提示区内：
- **已激活联携（搭档已选到对应技能）**：金色边框 + "✅ 炎壁已激活"
- **可激活联携（搭档技能可刷但还没选到）**：银色边框 + "🔗 炎壁：需要黄巾·坚壁"
- **无联携（当前阵容无此搭档）**：不显示联携提示区

#### 3.3.2 选牌前联携预览

每次三选一弹出前，先展示一个**瞬闪预览**（半透明浮层，0.8秒自动消失）：

```
本轮可选强化牌中：
  🔗 红衣·灼烧 → 与黄巾·坚壁 形成炎壁联携
  🔗 青衣·冻结 → 与A·弱点标记 形成碎冰联携
```

玩家在这个瞬闪里快速扫描："哪张牌有联携？"——然后带着这个信息去做三选一决策。**这就是"策略深度"的感知来源**——选牌不再是看哪个数值大，而是"哪个能激活联携"。

## 四、阵容联携（第三层·局外配阵）

### 4.1 规则

- **触发条件**：特定御灵组合同时上场
- **生效时机**：开局即生效（全场常驻被动）
- **局外显示**：编成界面上展示可用联携组合

### 4.2 首发阵容联携（参考红衣规格表第六章·配阵羁绊）

沿用已有的羁绊框架，但简化为"双将联携"（降低复杂度）：

| 联携名 | 组合 | 效果 |
|---|---|---|
| **焚炎双星** | 红衣 + 任一火系 | 红衣灼烧伤害+20% [PLACEHOLDER] |
| **盾壁同袍** | 黄巾 + 任一土系 | 黄巾获得额外10%最大生命值护盾开局 [PLACEHOLDER] |
| **冰影同行** | 青衣 + 任一水系 | 青衣的首次减速必然触发冻结 [PLACEHOLDER] |
| **猎魂共鸣** | A + 任一输出型 | A对精英/Boss伤害+15% [PLACEHOLDER] |
| **护命同心** | B + 任一前排 | B的治疗量+20% [PLACEHOLDER] |

### 4.3 局外配阵界面

编成界面展示：
- 当前阵容已激活的**阵容联携**（绿色高亮）
- 缺少一个就能激活的**近距联携**（黄色提示："红衣+青衣即可激活焚炎双星"）
- 未满足条件的联携（灰色）

## 五、联携与强化牌池的联动（控制随机性）

### 5.1 联携权重加成

当前阵容存在**未激活联携**时，下一轮三选一中：
- 联携技能牌的出现概率 **×2**（如红衣的"灼烧"出现概率翻倍，因为黄巾已经有"坚壁"但还没激活炎壁）
- 加成仅对**搭档已有对应技能、且联携触发方还没选到技能**的组合生效

### 5.2 联携完成彩蛋

当玩家完成一个联携时（例如选中红衣·灼烧，黄巾已经选了坚壁，成功激活"炎壁"），触发：
- **音效彩蛋**：清脆的"叮——"一声
- **瞬间视觉效果**：两道御灵之间闪过光链，然后消失
- **结算插页**：激活的联携会在结算时展示，增加成就感

## 六、联携系统的策略深度论证

### 6.1 三重联携分别对应三类玩家

| 联携层 | 对应玩家类型 | 策略决策 | 决策成本 |
|---|---|---|---|
| 阵位联携 | 新手/休闲 | "把红衣放黄巾旁边" | 极低，一眼看懂 |
| 技能联携 | 中度/核心 | "选灼烧牌激活炎壁，还是单选火力强化？" | 中等，需要预判搭档技能 |
| 阵容联携 | 重度/赛前策略 | "这个关卡用焚炎双星还是盾壁同袍？" | 较高，需要了解关卡特性 |

**三层递进**：新手先学会阵位联携（放一起有增益），随着对局深入开始理解技能联携（选牌有组合），终局玩家开始规划阵容联携（配阵有策略）。

### 6.2 联携对比纯数值强化的策略价值

| 强化牌类型 | 数值强化牌 | 联携技能牌 |
|---|---|---|
| 决策逻辑 | "哪张牌数值大？" | "哪张牌能激活联携？激活后效果值多少？" |
| 使用场景 | 任何阵容都能用 | 需要特定搭档在线 |
| 策略深度 | 浅 | 深 |
| 玩家满足感 | 低（"加了10%攻击"） | 高（"我激活了炎壁！"） |

### 6.3 联携系统与下场的天然契合

联携的存在理由跟"御灵下场"直接绑定：

```
城墙模式（城主别慌张）：塔是固定的 → 没有"谁靠近谁"的概念 → 联携无处附着
下场模式（御灵召来）：御灵有位置 → 守备范围重叠 → 联携有物理空间承载
```

**联携系统是需要下场模式才能成立的机制。** 这就是你回复领导的关键论证：
"我们不是'塔防加了角色移动'——我们是'角色下场让联携策略成为可能，这是城墙模式永远做不到的深度'。"

## 七、MVP落地规划（分阶段）

### 7.1 M1末·最小可验证（本周交付）

**只做阵位联携 + 强化牌联携提示UI**

- 3个御灵（红衣+黄巾+青衣）的阵位联携
- 强化牌卡面上显示联携提示（🔗格式）
- 联携完成彩蛋（简单音效）
- **验证目标**：玩家能否理解"放一起有增益"？选牌时能看懂联携提示吗？

### 7.2 M2·完整联携系统

- 5御灵全部的三重联携
- 阵容联携编成界面
- 联携权重加成
- 结算插页展示

### 7.3 工作量评估

| 内容 | M1末 | M2 |
|---|---|---|
| 阵位联携逻辑 | 3组 | 10组 |
| 技能联携逻辑 | 2组（做红衣的两组） | 全部10组 |
| 阵容联携逻辑 | 无 | 5组 |
| 强化牌UI改造 | ✅ | 打磨 |
| 联携彩蛋 | 简 | 全 |

**M1额外工作量**：约1-2天（阵位检测逻辑 + 强化牌卡面UI改造 + 音效），在W30调参周内可完成。
