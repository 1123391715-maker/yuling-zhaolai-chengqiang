# 红衣正式特效视觉需求稿 v1

状态：视觉需求稿，用于生成正式透明特效资源与后续工程接入。  
适用角色：红衣。  
接入原则：按 `AI_ENGINEERING_CONSTRAINTS.md` 与 `docs/AI美术UI接入工作流规范.md` 执行。  

本稿不是最终资源，也不代表已经接入完成。正式接入必须经过：视觉确认 → 资源拆分 → 透明资源生成 → 工程接入 → 实机截图校验。

## 1. 本轮目标

第一轮只做红衣的局内常用战斗特效，不重做整张战斗界面，不修改技能机制和数值。

本轮覆盖：

1. 普攻：焚符火羽
2. 普攻强化：业火爆燃
3. 普攻强化：凤羽齐射
4. 天赋触发：业火符积攒、赤莲火羽
5. 天赋强化：赤莲焚城、五瓣莲火、业火莲台

暂不优先覆盖：

1. 红衣大招：焚天火雨
2. 角色动作骨骼重做
3. 红衣立绘重画
4. 完整战斗界面重新生成

大招可以保留设计占位，后续单独做 v2。原因是大招属于全屏高密度特效，容易遮挡战场，需要单独校准亮度、密度和屏幕震动。

## 2. 红衣视觉定位

红衣的特效关键词：

- 朱红
- 橙金
- 符火
- 火羽
- 赤莲
- 灼烧
- 爆燃

需要和其他角色区分：

| 角色 | 视觉关键词 | 红衣需要避开的方向 |
| --- | --- | --- |
| 黄巾 | 金色、厚重、鼓波、山岳、镇压 | 不要做成金色冲击波或土石震荡 |
| 玄鸦 | 黑羽、飞刃、斩线、收割 | 不要做成黑色刀光或羽刃切割 |
| 青衣 | 青灯、圣光、辅助标记 | 不要偏青蓝或白光 |
| 素问 | 星针、星蚀、锁定落点 | 不要做成星点针雨 |

红衣应当是“火焰铺场型输出”：命中时亮、地面火区持续、强化后从点燃变成莲火扩张。

| 机制 | 工程 ID | 当前效果 | 正式特效方向 |

## 4. 正式资源清单

建议新增目录：

`assets/art/vfx/hongyi-final-v1/`

### 4.1 普攻火羽

| 项目 | 要求 |
| --- | --- |
| 文件名 | `hongyi-fire-feather-v1.png` |
| 类型 | 透明 PNG/WebP 单图 |
| 用途 | 红衣基础普攻、主火羽 |
| 建议源尺寸 | 256 × 128 |
| 游戏显示尺寸 | 长约 42-62px，宽约 18-28px |
| 视觉 | 像一枚燃烧的朱红羽符，不是普通火球 |
| 动画方式 | 代码旋转 + 位移 + 轻微尾迹 |
| 透明要求 | 背景 Alpha = 0，四角完全透明 |

美术要点：

- 头部尖锐，尾部有符纸烧裂感。
- 中心亮橙，边缘朱红，外轮廓少量金色描边。
- 不要做成圆形火球；红衣普攻要和普通火球拉开差异。

### 4.2 命中小爆点

| 项目 | 要求 |
| --- | --- |
| 文件名 | `hongyi-fire-hit-sheet-v1.png` |
| 类型 | 透明序列帧 |
| 建议帧数 | 6 帧，横向排列 |
| 建议源尺寸 | 6 × 160 × 160 |
| 游戏显示半径 | 34-54px |
| 用途 | 普攻命中、轻度火焰反馈 |

美术要点：

- 快速亮起、快速收束。
- 不能遮住怪物主体超过 0.2 秒。
- 可以有 2-3 片符火碎片飞散。

### 4.3 业火爆燃

| 项目 | 要求 |
| --- | --- |
| 文件名 | `hongyi-ember-burst-sheet-v1.png` |
| 类型 | 透明序列帧 |
| 建议帧数 | 8 帧，横向排列 |
| 建议源尺寸 | 8 × 220 × 220 |
| 游戏显示半径 | 80px / 100px / 95px 三档 |
| 用途 | E03 业火爆燃、连锁爆燃 |

对应尺寸：

| 触发 | 真实范围 | 视觉范围 |
| --- | --- | --- |
| E03 1 星爆燃 | 80px | 外圈亮边接近 80px |
| E03 2 星灼烧目标爆燃 | 100px | 外圈亮边接近 100px |
| E03 3 星连锁爆燃 | 95px | 外圈亮边接近 95px |

美术要点：

- 爆燃是“符火炸开”，不是炸弹爆炸。
- 第一帧中心亮，后续外圈扩散。
- 外圈边界要清楚，因为要对齐真实伤害范围。
- 爆燃结束后不能留下黑烟大块遮挡。

### 4.4 凤羽齐射侧羽

| 项目 | 要求 |
| --- | --- |
| 文件名 | `hongyi-fan-feather-v1.png` |
| 类型 | 透明 PNG/WebP 单图 |
| 建议源尺寸 | 220 × 110 |
| 游戏显示尺寸 | 长约 36-52px，宽约 14-22px |
| 用途 | E14 两侧火羽、第二轮火羽 |

美术要点：

- 和主火羽同源，但更细、更轻。
- 侧羽亮度低于主火羽 15%-25%。
- 第二轮齐射可以复用该资源，用代码降低透明度或加延迟残影。

### 4.5 业火符环绕

| 项目 | 要求 |
| --- | --- |
| 文件名 | `hongyi-sigil-v1.png` |
| 类型 | 透明 PNG/WebP 单图 |
| 建议源尺寸 | 96 × 128 |
| 游戏显示尺寸 | 14-22px |
| 用途 | 红衣身边业火符计数、赤莲火羽触发前提示 |

美术要点：

- 符纸形状要清楚，不要只是橙色小球。
- 5 枚符火环绕角色，达到数量后瞬间聚拢并触发赤莲火羽。
- 不能挡住角色头脸和脚下魂位。

## 5. 赤莲火区资源

### 5.1 赤莲火区

| 项目 | 要求 |
| --- | --- |
| 文件名 | `hongyi-lotus-fire-sheet-v1.png` |
| 类型 | 透明循环序列帧 |
| 建议帧数 | 8-12 帧 |
| 建议源尺寸 | 每帧 256 × 256 |
| 游戏基础半径 | 82px |
| 用途 | 业火莲心触发后的地面火区 |

美术要点：

- 地面是“赤莲火纹”，不是一坨圆形火。
- 中心低亮，边缘清楚；不要把怪物脚底完全盖住。
- 花瓣轮廓可见，但透明度要克制。
- 基础火区显示半径约 82px，边界与真实伤害范围偏差不超过 8px。

### 5.2 五瓣莲火

| 项目 | 要求 |
| --- | --- |
| 文件名 | `hongyi-lotus-petal-v1.png` |
| 类型 | 透明 PNG/WebP 或序列帧 |
| 建议源尺寸 | 220 × 140 |
| 游戏显示 | 从火区中心向敌潮方向延展 |
| 用途 | E16 1-2 星，火区变五瓣莲火、每秒延展莲瓣 |

美术要点：

- 主要向前方延展，侧向扩张较弱。
- 莲瓣像火舌，但有莲形轮廓。
- 不要横向铺满屏幕；红衣是铺火，不是全屏清场。

### 5.3 业火莲台

| 项目 | 要求 |
| --- | --- |
| 文件名 | `hongyi-lotus-platform-sheet-v1.png` |
| 类型 | 透明序列帧 |
| 建议帧数 | 8-12 帧 |
| 建议源尺寸 | 每帧 320 × 320 |
| 游戏显示半径 | 基础火区 135% 上限，约 110px |
| 用途 | E16 3 星，两个赤莲火区重叠融合 |

美术要点：

- 莲台是“融合后的阵火核心”，应该比普通火区更庄重。
- 允许有六向莲焰喷发，但喷发外沿不能超过真实范围太多。
- 中心可有符纹/莲心，不要做成金属法阵。
- 持续状态要能循环，不要每帧都像爆炸。

## 7. 资源生成要求

所有新增红衣特效资源必须满足：

1. 透明背景，Alpha 为真实透明。
2. 不包含战斗背景、怪物、角色、UI、箭头、标注文字。
3. 不使用整张战斗截图裁切。
4. 序列帧每帧大小一致。
5. 动画中心点稳定，不要每帧漂移。
6. 边缘无黑底、白边、色块残留。
7. 资源命名使用英文小写和短横线。
8. 保留源图与压缩图，源图可 PNG，工程图可 WebP。

## 9. 工程接入建议

新增资源注册位置：

- `src/config.js`

绘制替换位置：

- 红衣投射物：`src/game-wall.js` 的 `drawProjectiles`

配置校准位置：

- `config/skill-tuning.js`

| 参数 | 当前值 | 特效校准意义 |
| --- | --- | --- |
| 爆燃半径 | 80px | E03 1 星视觉边界 |
| 灼烧爆燃半径 | 100px | E03 2 星视觉边界 |

## 10. 实机验收截图

接入后至少输出 5 张截图：

1. 红衣无强化普攻命中
2. E03 业火爆燃
3. E14 凤羽齐射
4. 业火符满后赤莲火羽
5. E16 业火莲台

验收标准：

- 特效和真实攻击范围基本一致，偏差不超过 8px。
- 怪物主体仍能看清。
- 红衣脚下魂位、主角、血条不被长期遮挡。
- 同屏 20 个以上怪物时不糊成一片。
- 红衣特效明显比当前代码特效更精致。
- 红衣、黄巾、玄鸦三人的攻击形态一眼能分辨。

## 11. 禁止事项

- 禁止生成整张战斗界面截图作为资源。
- 禁止把背景、怪物、UI、血条、按钮烘进红衣特效图。
- 禁止用不透明黑底/灰底特效。
- 禁止把爆燃做成核爆白光，导致怪物不可读。
- 禁止把赤莲火区做得比真实伤害范围大很多。
- 禁止为了特效好看改变阵法比例、角色站位或战斗 UI。

## 13. 本轮完成定义

只有同时满足以下条件，才算“红衣正式特效 v1 完成”：

1. 视觉板已确认。
2. 透明资源已生成并通过 Alpha 检查。
3. 资源已拆分，不含背景和 UI。
4. 工程已接入当前 `src/game-wall.js` 分支。
5. 已输出实机截图。
6. 截图中尺寸、亮度、遮挡、范围边界通过验收。

如果只生成视觉图，不能称为完成。  
如果只用截图裁切覆盖，不能称为完成。  
如果没实机截图校验，只能称为初步接入。
