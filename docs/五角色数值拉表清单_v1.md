整理日期：2026-07-28

用途：在五角色技能定稿后，用统一表格验证 DPS、城防压力、控场效率、辅助覆盖率，避免凭感觉调参。

## 3. 黄巾专项拉表

| 指标 | 记录方式 | 首版目标 | 异常时调整 |
|---|---|---|---|
| 压阵平均层数 | 每 5s 统计怪群平均压阵层数 | 中线怪群 ≥1.2 层 | 提高命中范围或压阵持续 |
| 压阵减速覆盖率 | 有压阵的敌人 / 场上敌人 | 30%—55% | 不足则每层 -5% → -6% |
| 怪物首次攻击城防时间 | 记录每波首个攻击城防时间 | 比无黄巾延后 ≥1.5s | 提高击退距离或减速 |
| 聚山触发次数 | 每波触发次数 | 每波 3—8 次 | 太少则降低触发 CD 或扩大半径 |
| 聚山后群体密度 | 聚山后 1s 内目标附近敌人数 | 平均 +1.5 个敌人 | 提高拉近距离 |
| 红衣爆燃命中数变化 | 有 / 无黄巾对比 | 平均命中数提升 | 若无提升，聚山半径或位置需调 |
| 素问落针空落率 | 有 / 无黄巾对比 | 空落率下降 | 若无变化，说明控场没有帮助锁定 |

## 7. 初始调参优先级

若实战不舒服，按这个顺序调：

1. 先调怪物速度、城防预警线、怪物攻击距离，确保基础战斗正确。
2. 再调黄巾压阵减速和聚山，让怪潮形态稳定。
3. 再调红衣 / 素问 / 玄鸦输出，避免用伤害掩盖战斗路径问题。
4. 再调青衣照破和同辉覆盖率，避免辅助变常驻光环。
5. 最后调升星和局内强化，不要用高级强化修基础体验。

## 8. 首轮验收口径

首轮不是追求绝对平衡，而是确认五个角色的“感觉”成立：

- 黄巾上场后，怪潮明显被压住、被聚起来。
- 红衣上场后，怪群血线明显被火压低。
- 玄鸦上场后，残血敌人明显更难漏。
- 素问上场后，精英 / Boss 明显掉得更快。
- 青衣上场后，被照破的目标明显成为全队集火窗口。

只要这五句话成立，再进入精细数值平衡。
