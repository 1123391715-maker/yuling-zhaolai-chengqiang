# 《御灵召来》基础音效需求 v1

用途：把本文件交给音频 AI 或音效制作工具，先生成一套可进 Demo 的基础 SFX。第一版目标不是“最终商业级音频”，而是让 10 波战斗有明确反馈、节奏和爽感。

## 统一风格要求

- 题材气质：中式志怪、道法、符箓、幽野村、城墙守阵。
- 质感关键词：铜铃、符纸燃烧、风雨法术、鬼火、鼓点、短促打击、轻微灵气尾音。
- 禁止：明显现代枪械声、科幻激光感过强、英文/人声台词、过长旋律、恐怖尖叫。
- 文件格式：WAV 优先，48kHz / 24bit 或 44.1kHz / 16bit 均可。
- 响度：峰值建议 -6dB 左右，避免爆音；UI 音量比战斗音效低 20% 左右。
- 时长：普通反馈 0.1-0.5 秒；技能 0.6-1.4 秒；胜负结算 1.5-2.5 秒。
- 命名：全部小写英文 + 下划线，方便工程接入。

## 音量分层建议

- UI 点击：0.35
- 强化选择：0.55
- 普攻命中：0.45
- 普攻技能表现：0.55
- 主角技能/大招：0.75
- 城防受击：0.65
- Boss/胜负：0.8

## 第一版验收标准

- 同屏大量怪物死亡时不刺耳、不糊成一团。
- 红衣、黄巾、玄鸦三名首发角色的命中特征能听出差异。
- 强化牌品质能通过音效听出轻重：蓝色轻、黄色亮、红色重。
- 主角技能“呼风/唤雨”必须一听就知道是大范围手动技能。
- 所有音效可以被裁短循环触发，不依赖很长尾音。
