# 《御灵召来》局内角色技能、强化与基础关卡设计 v0.2

> 第二轮设计目标：把 v0.1 的“系统完整”推进到“选择有感觉、战斗有起伏、角色会配合”。  
> 适用范围：当前 5 名御灵、3 类敌人素材、20 波基础关卡、每波结束三选一。  
> 核心体验：五人自动迎敌，前排聚怪，后排压血，战士收割，辅助救场；玩家通过局内强化改变下一波的战斗方式。

---

## 1. 第二轮结论

### 1.1 保留内容

- 保留“通用 / 阵营 / 专属”三类强化。
- 保留“一波结束一次三选一”；第 20 波胜利后不再提供无意义的局内强化，改为结算奖励。
- 保留黄巾、红衣、青衣、玄鸦、素问的基础定位。
- 保留普通怪、精英怪、Boss 三种素材，不要求新增角色素材。
- 保留魂归、复活、阵法血量、七星灯、主角术法等现有系统。

### 1.2 必须解决的问题

1. 红衣从“单人清屏”调整为“群体铺火和压血”，收割工作交给玄鸦，精英/Boss处理交给素问。
2. 青衣从后台缓慢回血调整为能制造“差点阵亡—被救回来”的明确时刻。
3. 30 个强化不再只写百分比，每个强化必须具有可观察反馈。
4. 第 8—12 波主动制造第一次角色阵亡，让魂归系统成为正常体验，而不是极端失败才出现。
5. 后期不再只增加怪物总数，改为提高短时间密度、精英占比和危险窗口。

### 1.3 单局目标

| 指标 | 目标值 |
|---|---:|
| 单局总时长 | 8—11 分钟 |
| 普通波时长 | 15—28 秒 |
| Boss 波时长 | 45—65 秒 |
| 局内有效强化次数 | 19 次 |
| 单局出现机制变化 | 6—9 次 |
| 首次预期阵亡 | 第 8—12 波 |
| 单局常规阵亡次数 | 1—3 次 |
| 同屏敌人上限 | 32—36 个 |
| 单一角色伤害占比上限 | 常规不超过 45% |

## 2. 五人战斗关系

### 2.1 战斗链条

`黄巾拦截聚怪 → 红衣铺火压血 → 玄鸦斩杀残血 → 素问标记精英/Boss → 青衣维持阵线`

五名角色不是五个独立炮台，而应当相互创造条件：

- 黄巾阻挡的敌人更容易受到全队集火。
- 红衣制造灼烧，给玄鸦收割和素问穿透创造目标。
- 玄鸦击杀被压低血线的敌人，缓解黄巾阻挡压力。
- 素问让精英和 Boss 进入全队爆发窗口。
- 青衣把阵线从濒临崩溃拉回安全区。

### 2.2 目标战斗占比

| 角色 | 伤害占比目标 | 承伤/治疗目标 | 玩家应该看到的核心反馈 |
|---|---:|---:|---|
| 黄巾 | 6%—10% | 承受全队 55%—70% 角色伤害 | 怪物停在盾前、盾阵扩张、濒死后继续顶住 |
| 红衣 | 25%—35% | — | 火焰逐个扩散，怪物不是同一帧全部消失 |
| 玄鸦 | 20%—28% | 少量自保 | 冲入残血怪群，连续收割后退回站位 |
| 素问 | 22%—30% | — | 精英/Boss被标记后快速掉血，星针穿透 |
| 青衣 | 3%—6% | 提供主要治疗与护盾 | 低血角色被明显抬回、护盾挡住下一击 |

### 2.3 战斗节奏模板

每个普通波应包含四段，而不是从头到尾同一种密度：

1. **入场 0—4 秒**：小怪成组出现，展示上一轮强化。
2. **接敌 4—10 秒**：黄巾完成聚怪，远程开始铺伤害。
3. **压力 10—20 秒**：精英到达，前排掉血，青衣开始救场。
4. **收尾 20—28 秒**：玄鸦收割残血，素问处理剩余精英。

## 3. 五名角色 v0.2 技能

### 3.1 黄巾——阵线锚点

基础属性保持：HP 1000 / ATK 40 / DEF 60 / 攻速 0.8/s / 阻挡 3 / 射程 1 格。

**普攻：盾击**

- 100% ATK。
- 前摇 0.25s，后摇 0.35s，每 1.25s 一次。
- 30% 概率击退半格。
- 对已经被自己阻挡的目标增加更重的命中停顿，但不额外增加伤害。

**大招：坚壁领域，CD 14s**

- 获得最大 HP 30% 护盾，持续 6s。
- 护盾存在时，同列友方减伤 25%。
- 释放瞬间无敌 0.15s。

**被动：不动如山**

- 每存活 10s，DEF +8%，最多 5 层。
- 魂归复活后层数保留。

**设计边界**

- 黄巾应该能在第 8—12 波首次阵亡，但不能经常被普通怪瞬间击杀。
- 坚壁领域用于延缓崩线，不应让黄巾永久无伤。

### 3.2 红衣——铺火与群体压血

基础属性保持：HP 450 / ATK 100 / DEF 15 / 攻速 0.9/s / 阻挡 1 / 射程 3 格。

**普攻：火球术**

- 100% ATK。
- 弹道速度 350px/s；前摇 0.3s，后摇 0.35s。
- 灼烧：每秒 10% ATK，持续 3s，不叠加，只刷新持续时间。

**大招：焚天火雨，CD 18s**

- 对全场敌人造成 35% ATK 初始伤害。
- 施加每秒 10% ATK、持续 4s 的灼烧。
- 已经处于灼烧状态的敌人额外受到一次 25% ATK 余烬爆裂。
- 释放时无敌 0.3s。

**被动：余烬**

- 每有 1 个灼烧敌人，红衣 ATK +3%，最多 5 层，即 +15%。
- 满层时火球尺寸和拖尾增强，明确提示被动已满。

**设计边界**

- 无强化火雨总理论伤害约为 75% ATK；它负责铺火，不直接清屏。
- 红衣常规伤害占比控制在 25%—35%。
- 任何单张红衣强化不得让全屏火雨总伤害直接增加 200% ATK 以上。

### 3.3 青衣——救场辅助

基础属性保持：HP 600 / ATK 35 / DEF 35 / 攻速 0.9/s / 阻挡 1 / 射程 2 格。

**普攻：圣光弹**

- 80% ATK，弹道速度 380px/s。
- 保持较低伤害，不与输出职业争夺职责。

**大招：群体治愈，CD 13s**

- 全队回复 250% ATK，约 88 HP。
- 全队获得等于本次治疗量 60% 的护盾，持续 4s。
- 治疗数字、护盾外圈和全队光柱必须同时出现。

**被动：圣光眷顾**

- 每 3s 治疗生命百分比最低且非满血的友方，回复 130% ATK，约 46 HP。
- 目标低于 35% HP 时，本次改为 200% ATK，约 70 HP。
- 全队满血时不空放。

**光环：圣光庇护**

- 周围 2 格友方受到治疗 +25%，自身不享受。

**设计边界**

- 青衣必须能救回濒死角色，但不能把所有伤害完全抹平。
- 玩家每 10—15 秒至少看到一次明确的治疗或护盾反馈。

### 3.4 玄鸦——近战收割者

基础属性保持：HP 720 / ATK 78 / DEF 28 / 攻速 1.15/s / 阻挡 2 / 射程 1 格。

**普攻：鸦影斩**

- 100% ATK。
- 裂伤：每秒 10% ATK，持续 2s，不叠加。
- 对 HP 低于 35% 的敌人伤害 +20%。

**大招：玄鸦掠阵，CD 15s**

- 优先选择 Boss，其次选择当前 HP 最高的精英。
- 对目标附近连续斩击 3 次，每次 80% ATK，总计 240%。
- 施加破绽 4s：受到坦克/战士伤害 +20%。

**被动：鸦羽追击**

- 击杀后攻速 +20%，持续 3s，最多 3 层。
- 满层后下一次普攻变成 130% ATK 小范围横扫，触发后清空层数。

**设计边界**

- 玄鸦的爽点来自连续斩杀，不来自对满血怪群的大范围爆发。
- 红衣把怪物压到残血后，玄鸦的收割效率必须明显上升。

### 3.5 素问——精英与 Boss 破防核心

基础属性保持：HP 520 / ATK 82 / DEF 20 / 攻速 0.85/s / 阻挡 1 / 射程 3 格。

**普攻：星针**

- 90% ATK，弹道速度 430px/s。
- 目标带有灼烧、裂伤、破绽、破法或问命签时，穿透 1 个额外敌人。

**大招：太素星落，CD 17s**

- 在敌人最密集区域造成 5 次 18% ATK 星落，总计 90%，最多命中 6 个目标，优先精英与 Boss。
- 破法持续 5s：DEF -20%，受到技能伤害 +10%。

**被动：问命签**

- 每 6s 标记当前 HP 最高的敌人，持续 5s。
- 标记目标受到全队伤害 +15%。
- 标记目标死亡时，素问大招 CD -1s。

**设计边界**

- 素问对普通怪的清理速度不超过红衣。
- 精英和 Boss 出场时，素问应明显接近或超过红衣的有效伤害。

## 4. 强化的统一规则

### 4.1 每张牌都包含两层收益

每张强化必须同时包含：

1. **持续收益**：真正改变后续战斗数值或机制。
2. **获得反馈**：选择后 1 秒内可见，或在下一波前 3 秒内保证触发一次。

不能只弹出“攻击 +10%”文字就结束。卡面标题优先描述行为，例如“火球会分裂”，数值放在第二行。

### 4.2 选择反馈时间线

- 0—0.2s：卡牌飞向受影响角色或阵法。
- 0.2—0.55s：角色轮廓亮起，出现强化名称。
- 0.55—0.9s：血条、技能图标、灵灯或武器产生对应变化。
- 下一波 0—3s：保证展示一次强化后的攻击、护盾、治疗、连击或灯阵反馈。

### 4.3 单张强度预算

| 类型 | 单级期望提升 | 设计限制 |
|---|---:|---|
| 通用普通 | 全队有效强度 6%—10% | 稳定但不改变核心玩法 |
| 阵营普通/稀有 | 对应角色 12%—20%，并给全队创造条件 | 不能只是单角色数值 |
| 专属普通/稀有 | 对应角色 15%—25% | 优先改变攻击形态 |
| 传说 | 单次构筑提升 20%—35% | 改规则，不允许纯粹给超大倍率 |

## 6. 三选一刷新规则 v0.2

每次提供三个不同职责的选项：

1. **安全位**：通用牌或玩家已经选择过的可升级强化，保证构筑能继续成长。
2. **构筑位**：当前上阵阵营或角色的阵营/专属牌。
3. **变化位**：尚未选择的机制牌、稀有牌或满足条件的传说牌。

附加规则：

- 已选择的可升级强化，后续刷新权重提高至基础的 1.6 倍。
- 连续两轮没有出现机制牌时，下一轮变化位必出机制牌。
- 传说牌第 5 波后才可出现。
- U09“天命重燃”第 8 波后，或本局首次有角色阵亡后进入池子。
- 第 5 波后保证至少一张稀有牌。
- 第 10 波后保证至少一张专属牌。
- 第 15 波后保证至少一张稀有或已选强化升级牌。
- 第 19 波若本局尚未获得传说，保证一个符合阵容的传说选项，作为 Boss 前构筑收束。
- 同一轮不能出现两张作用高度相同的纯数值牌，例如“攻击提升”和“技能伤害提升”不能同时占两个位置。
- 第 20 波胜利后进入结算，不再出现局内强化。

### 6.1 卡面必须展示的信息

- 第一行：行为变化，如“火球分裂为两枚余烬”。
- 第二行：本级精确数值。
- 角标：通用 / 阵营 / 专属，普通 / 稀有 / 传说。
- 受影响角色头像。
- 若为升级牌，显示“Lv.1 → Lv.2”以及新增内容，不能只显示最终描述。
- 机制质变使用短视频式循环预览或简化动态图标，不依赖长文本理解。

## 7. 敌人数值与压力结构 v0.2

### 7.1 基础敌人

|---|---:|---:|---:|---:|---:|---|

数值目的：

- 普通怪不被无强化红衣火球直接秒杀，火球命中后会留下短暂灼烧观察窗口。
- 精英早期需要 5—8 秒处理，后期成型后约 3—5 秒。
- Boss战目标持续 45—65 秒，确保至少经历两轮角色大招。

### 7.2 不新增素材的波次词条

仍然只有普通、精英、Boss三种敌人，但部分波次可以给同类敌人附加统一词条，用轮廓和粒子区分：

| 词条 | 效果 | 视觉 |
|---|---|---|
| 急行 | 移速 +25%，ATK -10% | 青白色脚底风线 |

| 狂袭 | ATK +20%，最大 HP -10% | 红色手臂残影 |

同一波最多使用一个词条，避免玩家阅读负担。

### 7.3 Boss阶段

- **100%—70%：召纸**——每 9s 召唤 4 个符纸游魂，让玩家熟悉 Boss 节奏。
- **70%—40%：红线**——每 12s 标记后排最低血角色，1s 后造成 150% ATK；青衣护盾使该伤害 -35%。
- **40%—15%：破阵**——吟唱 1.5s 对阵法造成 150 点伤害，同时召唤 1 个镇魂甲尸。
- **15%以下：魇主狂化**——攻速 +20%，召唤间隔缩短，但不再额外提高单次攻击力。

Boss技能必须有 0.8—1.5s 可识别预警，玩家虽不能直接操控御灵，但可以决定是否手动释放主角术法。

### 8.1 波次强度不是只看总数量

每波调试时同时记录：

- 第一只敌人接触黄巾的时间。
- 黄巾第一次低于 50% HP 的时间。
- 同屏峰值敌人数。
- 精英同时被阻挡的峰值。
- 角色首次阵亡波次。
- 波次完成时间。

如果一波过弱，优先调整“同批数量”和“精英到场时间”；最后才增加总怪数。这样能提高压迫感而不会单纯拖长关卡。

## 9. 平衡验收标准

### 9.1 角色

- 无强化红衣大招不能直接消灭满血普通怪。
- 红衣取得 E03 后清杂明显提升，但单人伤害占比仍尽量不超过 45%。
- 有精英/Boss时，素问的有效伤害应显著提升。
- 玄鸦至少 35% 的击杀来自生命低于 35% 的目标，证明其确实在收割。
- 黄巾在第 10 波附近存在阵亡概率，但不是每次必死。
- 青衣一次大招后，至少一名低血角色能多承受一轮精英攻击。

### 9.2 强化

- 选择强化后 1 秒内必须有视觉反馈。
- 下一波开始 3 秒内，玩家至少看到一次与所选强化对应的真实战斗结果。
- 普通强化单级让波次完成时间或生存能力改善约 6%—10%。
- 专属/阵营强化让对应玩法改善约 12%—25%。
- 单张传说不能让某角色伤害翻倍以上。
- 一局 19 次选择中，玩家应获得 6—9 个攻击形态或规则变化，而不只是百分比累加。

### 9.3 关卡

- 第 1—5 波基本不阵亡。
- 第 8—12 波约 50%—70% 的普通构筑能看到一次魂归。
- 第 17—20 波允许出现 1—2 名角色短暂阵亡，但不应因此立刻失败。
- Boss战至少经历一次红线、一次破阵和两轮角色大招。
- 普通胜利构筑的阵法剩余 HP 目标为 20%—60%，避免全程无压力或必然残血。

## 10. 接入顺序

### P0：先解决当前体感

1. 按 v0.2 调整红衣、青衣、玄鸦和素问数值。
2. 调整普通怪 HP，使红衣普攻不再无条件秒杀。
3. 替换 20 波数量与第 10 波压力脚本。
4. 先接入最容易看见的 10 张机制强化：U05、U07、U09、F02、F06、F08、E01、E03、E05、E09。

### P1：建立完整构筑

1. 接入全部 30 张强化。
2. 加入安全位 / 构筑位 / 变化位刷新逻辑。
3. 加入“获得后反馈”和“下一波保证展示”机制。
4. 在战斗数据面板增加角色伤害、治疗、承伤和击杀占比。

### P2：完成关卡节奏

1. 接入急行、硬壳、狂袭三个波次词条。
2. 完成 Boss 四阶段与技能预警。
3. 根据实测数据调整首死波次、单局时长和阵法剩余 HP。

## 11. 与 v0.1 的关键差异

- 红衣火雨由“全屏输出答案”变为“铺火与压血工具”。
- 青衣提高低血救场能力，治疗反馈更集中。
- 玄鸦明确获得残血收割职责。
- 素问大招总倍率略降，但对精英/Boss的团队价值更明确。
- U10 不再根据固定五阵营直接获得常驻 +30% 伤害和 -20% 受伤，改为需要三名角色连续施法触发。
- E04 不再追加三次 120% ATK 全场爆炸，改成三个有落点、有预警的 55% ATK 局部火莲。
- 阵营牌开始给全队创造条件，不再等同于单角色专属牌。
- 第 10 波不再出现 Boss，改为第一次魂归压力波；Boss只在第20波出现。
- 后期怪物总量降低，通过精英、批次与词条制造强度。
- 第20波胜利后直接结算，局内有效强化为19次。
