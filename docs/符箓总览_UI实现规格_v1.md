# 符箓总览 UI 实现规格 v1

## 1. 定稿依据

- 画布：`750 × 1334` 逻辑像素，竖屏。
- 入口视觉：`artifacts/fu-lu-icons-scale-preview-v4.png`；采用现有右侧圆形金边控制按钮语言。
- 总览弹窗：使用本次生成并确认的「铜金边框 + 青焰 + 羊皮纸」资源，不使用截图、临时 Canvas 框或竞品素材替代。
- 本文是实现、资源切图、适配和验收的唯一依据。

## 2. 功能口径

### 2.1 角色强化数量

- 数量仅统计**实际生效的不同强化条目**；同一条从 1 星升级至 2 / 3 星不增加数量。
- `通用`：所有上阵御灵各计 1 条；`阵营`：仅匹配阵营的御灵各计 1 条；`专属`：仅指定御灵计 1 条。
- 数量为 0 时不绘制徽章。
- 徽章常驻角色脚侧，显示范围 `1–99`。

### 2.2 符箓总览

- 点击右侧「符箓」按钮打开；打开时暂停战斗，关闭时恢复打开前的暂停状态。
- 顶部英雄头像切换查看；列表仅显示该英雄实际生效的强化。
- 列表按首次获得时间倒序；星级升级不改变条目顺序。
- 单条显示：品质框、技能图标、强化名、当前星级、类型标签、当前等级描述。
- 每屏显示 3 条；点击底部上一条 / 下一条翻页。无生效强化时显示空状态。

## 4. 字体、颜色、材质

- 字体栈：`Microsoft YaHei`, `PingFang SC`, sans-serif。
- 文字均使用无阴影的锐利绘制路径，避免小字号在 Canvas 中发糊。
- 标题：32px / 900 / `#4A2D0C`，在浅金标题牌上保持清晰对比。
- 条目名：21px / 900；普通 `#E8FBFF`、稀有 `#FFF0CB`、传说 `#FFF0C6`。
- 条目描述：15px / 700；普通 `#D7EDF0`、稀有 `#F7E4BF`、传说 `#FFE4BD`，最多两行。
- 品质框：普通蓝银、稀有琥珀橙、传说朱红金；颜色强度依次递增。
- 入口：双层古金环、墨蓝内芯、青色旋纹、金色符纸与朱印。
- 徽章：暖黄放射底、细金边、左上高光；不附加符纸、玉佩、飘带等会干扰数字识别的装饰。

## 6. 交互状态

| 状态 | 视觉 | 行为 |
| --- | --- | --- |
| 默认 | 入口静止；有生效强化的英雄显示数量徽章 | 可打开总览 |
| 新获得强化 | 现有强化即时反馈继续生效；徽章数当帧更新 | 同一强化升星只改星级 |
| 弹窗打开 | 战斗冻结、全屏压暗、选中头像金色高亮 | 点击头像切换；点击翻页切换列表 |
| 关闭 | 右上角 X 或弹窗外侧 | 恢复打开前暂停态 |
| 空状态 | 羊皮纸内容区显示说明，不制造伪条目 | 可切换其他英雄或关闭 |

## 7. 适配规则

- 全部数值基于 750×1334 逻辑画布；由现有 Canvas 缩放统一适配，不读取物理屏幕像素。
- 主面板保持源图比例，防止圆形关闭座和金边被拉伸。
- 右侧入口永远置于倍速下方；不与底部法器、灵灯区重叠。
- 徽章层位于英雄立绘上方、状态条下方；无需根据角色图片尺寸单独切换。
- 小屏幕沿用画布整体 contain 映射，不裁剪面板内容。

## 8. 验收与叠图校准

1. 用第 1 波实机截图生成 `artifacts/talisman-ui-runtime-v1.png`。
2. 与 `artifacts/fu-lu-icons-scale-preview-v4.png` 以 50% 透明度叠加，核对入口中心、徽章尺寸与脚侧位置。
3. 打开弹窗后核对：面板不变形、标题和关闭按钮居中、头像间距一致、三种品质框与文本不溢出。
4. 对 0 条、1 条、3 条、4 条及同一强化升星分别验证数量与分页。
5. 将截图、叠图和偏差写入 `docs/测试记录.md`；偏差超过 3px 才调整标注值。
