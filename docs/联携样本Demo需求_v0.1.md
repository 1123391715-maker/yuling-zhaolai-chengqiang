## 三、UI 规格

### 3.1 强化牌卡面（选牌时展示）

```
┌─────────────────────────────────────┐
│ 🔴 红衣 · 灼烧                      │  ← 御灵图标 + 技能名
│ 普攻线 · 节点3                     │
│                                     │
│ 火球命中后附加灼烧                 │  ← 效果简述（1行）
│ 3秒内每秒造成30%攻击力火伤         │
│                                     │
│ ┌─ 联携提示 ──────────────────────┐ │
│ │ 🔗 炎壁                         │ │
│ │ 需要：黄巾·坚壁                 │ │
│ │ 效果：黄巾阻挡的敌人全染灼烧     │ │
│ │ 状态：✅ 可激活（黄巾已选坚壁）  │ │  ← 金色
│ └────────────────────────────────┘ │
│                                     │
│              [ 选择 ]               │
└─────────────────────────────────────┘

联携状态三种颜色：
- 金色边框 + "✅ 已激活"：搭档已选了对应技能，选这张牌立刻激活联携
- 银色边框 + "🔗 可激活"：搭档技能还没选到，选了这张牌是"预备"
- 不显示联携区：当前阵容没有联携搭档
```

### 3.2 瞬闪预览（选牌前 0.8 秒浮层）

选牌弹出前，先在画面中央显示半透明浮层（0.8秒自动消失）：

```
┌────────────────────────────────┐
│  ⚡ 本轮可选联携               │
│                                │
│  🔗 炎壁（红衣·灼烧）          │
│     黄巾已选坚壁 → 可选此激活  │
│                                │
│  🔗 霜火（红衣·灼烧）          │
│     青衣·凝滞未选 → 预备      │
│                                │
│  💡 联携激活后的技能效果       │
│     比单选提升大               │
└────────────────────────────────┘
```

浮层样式：
- 半透明深色背景（60%不透明度）
- 从画面中央放大出现（scale 0→1，duration 0.3s）
- 0.8秒后自动淡出消失
- 文字黑色，🔗图标金色

### 3.3 阵位联携视觉（战斗中常驻）

- 当两个御灵满足阵位联携时：一条半透明水墨连线在他们之间出现
- 焚葬阵 = 金色连线
- 守魂阵 = 蓝色连线
- 联携断开时（御灵魂归、守备范围不再覆盖）：连线溶解消失

## 四、联携与选牌的联动逻辑（简单版）

每轮三选一出现时执行以下逻辑：

```
1. 扫描当前阵容中已激活的阵位联携
2. 扫描已选的技能（黄巾选了坚壁？红衣选了灼烧？）
3. 生成本轮"可激活联携"列表
4. 如果本轮随机到的牌中有关联可激活联携的牌 → 在该牌卡面上显示联携提示
5. 如果本轮没有任何联携相关牌 → 不显示联携提示（降级为普通三选一）
```

**本月不做**：联携权重加成（让联携牌出现概率翻倍），怕让领导觉得"你们故意引导玩家走联携"。先让联携牌**自然随机出现**，保持公平感。

## 五、给领导看的 Demo 流程（预计 5 分钟体验）

导演脚本：

```
0:00-0:20
  开局，玩家确认五魂位（实际只出3个）

0:20-1:00
  前3波，普通近战怪，3御灵各自守住锚点
  玩家注意到：黄巾在中军、红衣在左翼 → 守备范围重叠 → 出现金色连线
  这就是"焚葬阵"——红衣服的阵位联携自动激活

1:00-1:30
  第4波，快速突进怪绕过了红衣的守备范围
  玩家开始观察：黄巾在扛、红衣在打、青衣在减速
  第5波精英出现了——玩家意识到压力来了

1:30-2:30
  升级！三选一弹出前，瞬闪预览展示：
  "⚡ 本轮可选联携：🔗 炎壁（红衣·灼烧），黄巾已选坚壁 → 可选此激活"
  玩家看到三张牌，其中一张红衣·灼烧标着金色联携框

  玩家选择红衣·灼烧 → 激活炎壁
  联携激活瞬间：黄巾身上闪过红色光晕，黄巾挡住的敌人全部现身灼烧

2:30-4:00
  第6-9波，压力继续
  再次升级 → 瞬闪又展示联携 → 玩家选了青衣·凝滞 → 为霜火做准备
  第10波Boss前，联携已激活2组，防线稳固

4:00-5:00
  玩家停下来观察这个防线：
  - 黄巾在扛，红衣服灼烧她挡住的敌人（炎壁在运转）
  - 红衣的灼烧+青衣的减速完成了"霜火"组合
  - 几条水墨连线贯穿防御阵型
  玩家感受到：这是一个"有策略的防线"，不是"一堆人在打"

  Boss关 → 魂归 → 返场 → 联携重新建立 → 防线重组 → 通关
```

## 六、验收标准（领导看了打勾）

| # | 验收项 | 领导能看到什么 |
|---|---|---|
| 1 | 阵位联携视觉可见 | 看到两个御灵之间有金色/蓝色连线 |
| 2 | 阵位联携有"放一起就变强"的感知 | 看到联携图标/提示，理解"守备范围重叠=联携" |
| 3 | 强化牌上有联携提示 | 牌面上看到🔗和联携名 |
| 4 | 选牌前有瞬闪预览 | 选牌前0.8秒出现联携推荐 |
| 5 | 联携激活有视觉反馈 | 看到炎壁激活→黄巾身上红光闪过 |
| 6 | 联携激活后战场变化可见 | 看到黄巾挡住的敌人染上灼烧 |
| 7 | 一局至少激活1个联携 | 10波内有1-2个联携被激活和运转 |
| 8 | 领导能理解"联携=卡牌策略深度" | 不需要长篇解释，演示视频说明一切 |

## 七、开发步骤（按优先级）

### 第一步：阵位联携逻辑（周二上午）
- 检测守备范围重叠 → 触发阵位联携
- 联携效果生效（黄巾防御+15%、红衣伤害+8%）
- 联携断开检测（魂归时/守备范围不再覆盖）

### 第二步：阵位联携视觉（周二下午）
- 两个御灵之间的水墨连线
- 连线颜色区分（金=焚葬阵、蓝=守魂阵）
- 连线溶解消失动画

### 第三步：强化牌卡面改造（周二晚上）
- 卡面上加联携提示区
- 状态判断：已激活/可激活/无联携
- 金色/银色边框渲染

### 第四步：瞬闪预览（周三上午）
- 选牌前 0.8s 浮层
- 浮层内容生成（扫描当前阵容）
- 入场/退场动画

### 第五步：技能联携激活逻辑（周三下午）
- 两张技能牌联动检测
- 炎壁效果：黄巾阻挡敌人→自动附加灼烧
- 霜火效果：灼烧+减速→伤害翻倍

### 第六步：录屏 + 导出（周三晚上/周四上午）
- 按"导演脚本"录一段 5 分钟演示
- 发给领导 + 附上简短的说明文字

## 八、给领导的说明文字（录屏发完直接粘）

> "这是联携策略样本——做了两个联携层：
> 
> 第一层阵位联携：两个御灵守备范围重叠时自动触发。红线是焚葬阵（红衣+黄巾），蓝线是守魂阵（黄巾+青衣）。放一起就变强，这是空间策略。
> 
> 第二层技能联携：选牌时激活组合。视频里红衣·灼烧+黄巾·坚壁=炎壁（黄巾挡住的敌人自动染上灼烧），红衣·灼烧+青衣·凝滞=霜火（灼烧+减速伤害翻倍）。选牌不只是数值，是激活一个组合——这是卡牌策略。
> 
> 选牌前的瞬闪预览会提示'本轮可激活哪些联携'，让玩家带着信息做三选一决策。
> 
> 10波能激活1-2个联携，后续20波可以激活更多层次。你先看看这个联携样本的方向对不对，对了我就继续往5御灵20波填。"
