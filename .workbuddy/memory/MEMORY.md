# 御灵召来 · 项目长期记忆

> 项目级长期约定与关键事实，跨会话沉淀。每日日志详见 `YYYY-MM-DD.md`。

## 项目基本信息
- **名称**：御灵召来
- **品类**：卡牌 + 塔防 + 肉鸽（微信小游戏 / IAP）
- **题材**：中式诡异奇幻
- **美术**：2D 手绘 · 水墨工笔 + 诡异线条
- **参考产品**：《向僵尸开炮》（靶心Like肉鸽塔防）、《城主别慌张》（割草塔防+卡牌+SLG）

## 设计支柱（不可妥协）
1. 诡而有据——机制有中式神秘学根据，非贴皮
2. 一念之差——肉鸽选择是可见风险/收益博弈
3. 万法归阵——风水阵空间策略是塔防核心深度
4. 鬼有所归——御灵有人格有故事，收集有情感
5. 随而不虐——随机强但永远留可控退路

## 五大差异化卖点
1. 中式诡异奇幻题材（赛道空白）
2. 双层肉鸽（局内符箓 + 局外道行 Meta，Hades 式）
3. 风水阵法空间策略（阵位 + 五行相生相克 + 阵法共鸣）
4. 阴阳双资源 + 百鬼夜行风险博弈
5. 凶兆镇煞/迎煞关卡级主动博弈

## 关键设计约定
- **不做 SLG**：规避《城主别慌张》SLG 前置劝退痛点
- **道行不可购买**：Meta 成长只随游玩，保证零氪公平
- **失败也产出**：单局失败按波次结算，不归零（P5）
- **数值全部 PLACEHOLDER**：须纸面推演+试玩验证后转正

## 核心系统
- 御灵召唤（卡牌，阴阳五行，配阵羁绊如"五鬼运财""二十八宿"）
- **御灵技能树（4.1，核心）**：每个御灵4条技能线——普攻线/必杀线/天赋线/光环线，同线堆叠到阈值触发"技能进化"（机制质变非纯数值）
- **双层符箓结构（v0.3）**：
  - 局外层=符印（5.6）：战前装配的御灵专属技能铭刻，抽卡获取，永久持有。分御灵专属符印+通用五行符印。定起点/给方向/付费深度。战力占比目标20-30%
  - 局内层=符箓（4.2）：局内肉鸽，按场上御灵动态生成卡池，强化技能线节点，局后清零。定流派/给成长/肉鸽爽点
  - 协同：符印定起点，符箓定流派，阵法定空间。符印不能太强（超40%即压制肉鸽）
- 风水阵法（5×3盘，阵位五行，阵法共鸣，阵眼=防线）
- 阴阳双资源（阳气召唤/释放必杀，阴气百鬼夜行）
- 诡事凶兆（镇煞消除/迎煞翻倍）
- 道行 Meta 树（5支线，永久变异）

## 六层养成边界（v0.5 法器重构）
1. 御灵=角色卡（升星含属性+技能槽+技能线强化潜力上限，原道法树已合并）
2. 符印=御灵专属技能铭刻（战前装配，定起点）
3. 法器=混合式装备（v0.5重构）：全局通用槽4部位（傩面/法袍/灵符/镇魂铃，对应宝石洗练，大R付费深度）+御灵专属槽2部位（罗盘/招魂幡，本命法器，角色养成情感）
4. 神魂幻形=皮肤+初始词条（外观向）
5. 道行Meta=永久变异（不可购买）
6. 符箓=局内肉鸽（局后清零，强化技能线节点）

## 关键设计决策记录
- v0.2 符箓转向：以御灵为战斗主体，符箓强化御灵技能线而非独立道法。代价是御灵技能设计工作量上升，首发御灵数量可能从40下调至30
- v0.3 双层符箓：纯战前装配会动摇肉鸽基础，纯局内肉鸽缺战前策略与付费深度。双层并存解。新增符印系统作为局外配卡层
- v0.4 道法树合并进升星：局内符箓（肉鸽）不可并入升星（那是肉鸽维度载体，并入则项目退化为纯卡牌塔防）。但道法树（局外潜力上限）与升星功能重叠，合并精简，养成分支7→6层。道法残卷转升星辅材

## 项目计划
- ⚠ 存在两版规划，开发模式不同：
  - **GDD 版（早期，团队制）**：总周期14月，总预算¥780万，团队18人，M1(2月)→M2(3月)→M3(5月)→M4(2月)→M5(2月)
  - **立项说明书版（当前，单人+AI，用户2026-07-03确认）**：单人开发+AI辅助，预算约¥0.8-1.5万，M1核心战斗验证(4周)→M2垂直切片(6-8周)→M3产品测试(10-14周)→M4商业化评估。M1不通过则重构返场规则
- M1 Go/No-Go：内部试玩 70%+ 认为"想再玩一局"
- 当前阶段：M1 核心战斗验证立项（有条件立项）
- 注：v0.2 立项说明相比 GDD 大幅做减法——首版不做五行复杂反应、法器装备、局外肉鸽树、凶兆下注、百鬼夜行、抽卡池；聚焦"御灵下场阻挡+魂归换位+五角色技能构筑"
