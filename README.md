# 御灵召来 · 战斗 Demo

一款中式志怪题材的竖屏自动防守 Roguelite。五名御灵会进入战场移动、索敌、阻挡并攻击从上方来袭的鬼潮；御灵战败后进入“魂归”，玩家通过调整阵法中的虚影，决定其下一次返场位置。

## 直接试玩

双击根目录的 **`启动本地试玩.cmd`**。浏览器会打开：

`http://127.0.0.1:4173/`

如果 4173 端口被占用，可在 PowerShell 中运行：

```powershell
.\tools\serve.ps1 -Port 4174
```

再打开 `http://127.0.0.1:4174/`。

## 核心操作

- 拖动底部阵法中的御灵虚影：交换两名御灵的魂位。存活御灵不会立即移动，下一次魂归结束后从新位置返场。
- 击杀敌人获得全队共享经验；升级时从三张角色专属强化牌中选择一张。
- 道士携带焚火符、摄魂铃与渡水锋，战斗中按照敌情自动释放。
- 右侧功能栏提供暂停、战斗数据、1–3 倍速和敌情说明。
- 战斗数据可查看每名御灵的伤害、治疗、阻挡与魂归次数。

## 微信小游戏预览

1. 打开微信开发者工具，选择“小游戏”。
2. 导入本项目根目录。
3. 没有正式 AppID 时可使用测试号；`project.config.json` 默认填写 `touristappid`。
4. 点击“编译”即可从 `game.js` 启动。

项目使用原生 Canvas 2D，不依赖 DOM、npm 包或网络请求。浏览器入口和微信小游戏入口共用同一套战斗代码。

## 调整每波敌人数量

直接编辑 `config/waves.js`。每一行对应一波：

```js
{ stage: '1-3', spawnInterval: 0.78, enemies: { wisp: 7, jiangshi: 3 } }
```

将 `wisp: 7` 改为 `wisp: 12`，该波就会刷新 12 只游魂。支持 `wisp`、`jiangshi`、`armored`、`boss` 四种敌人；`spawnInterval` 控制出怪间隔。

修改后必须刷新页面或重新双击 `启动本地试玩.cmd`，并重新开始一局。已经进行中的对局不会热更新配置；战斗顶部的“详情”可查看当前波实际读取到的数量。

## 调整角色普攻

直接编辑 `config/heroes.js`：

```js
hongyi: { type: 'ranged', interval: 1.05, multiplier: 1, range: 230, windup: .24 }
```

`interval` 是普攻间隔秒数，`multiplier: 1` 表示造成攻击力 100% 的伤害，`range` 是攻击范围，`type` 可设为 `ranged` 或 `melee`。

## Demo 内容

- 20 波完整战斗，第 10 波中段 Boss、第 20 波终局 Boss“纸扎人”会周期召唤替身。
- 红衣、玄鸦、黄巾、素问、青衣五名御灵，分别负责范围输出、精英猎杀、多重阻挡、治疗守护与减速控场。
- 御灵拥有独立生命、阻挡数、索敌范围、攻击范围和统一魂归冷却。
- 每名御灵具备普攻、被动、必杀三条局内强化线，每条最多三阶并产生机制变化。
- 3 种道士术法根据敌情自动选取目标并释放。
- 胜利、失败均按波次结算，支持一键再开。
- 粒子、伤害飘字、屏幕震动、程序化音效和移动端自适应。

## 目录

```text
game.js / game.json       微信小游戏入口与配置
index.html                本地浏览器入口
src/                      跨端运行时、战斗逻辑、绘制与音频
assets/art/               生成式美术及压缩后的运行资源
tools/serve.ps1           零依赖本地预览服务
```

运行时使用压缩 WebP 精灵；高分辨率 PNG 源图已配置为微信首包忽略项。
